# 🖥 hospital-admin

医院预约挂号系统后台管理端。

基于 Vue3 + Element Plus 开发，实现医院后台管理功能。

---

# 🚀 技术栈

- Vue3
- Vite
- Element Plus
- Pinia
- Vue Router
- Axios

---

# ✨ 功能模块

- 管理员登录
- 用户管理
- 医生管理
- 科室管理
- 排班管理
- 预约管理
- 公告管理
- 数据统计

# 📦 项目启动

## 安装依赖

```bash
pnpm install
```

---

## 启动项目

```bash
pnpm dev
```

---

## 打包项目

```bash
pnpm build
```
